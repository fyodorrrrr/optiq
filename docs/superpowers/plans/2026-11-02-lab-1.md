# Lab 1 Implementation Plan

**Goal:** Replace the Lab 1 browser prototype with the required Python/OpenCV experiments and React interface.

**References:** `docs/LAB_REQUIREMENTS.md` Lab 1, `docs/PRD.md`, `docs/DESIGN_FOUNDATION.md`, and the approved workspace prototype.

**Design:** independent operations always start from the original. A stateless FastAPI router accepts bounded PNG/JPEG uploads and typed operation settings. An image service performs decoding, normalization, metadata extraction, OpenCV processing, and PNG encoding. React holds source/result state and rejects stale responses when inputs change. No server storage or database.

**Implementation choices:** top-left zero-based `(x, y)` coordinates; crop uses left/top/width/height; clockwise 90-degree rotation; explicit resize interpolation. Accept 8-bit grayscale/RGB/RGBA PNG and JPEG up to 5 MiB, 4096px per side, and four million pixels. Composite alpha onto white and disclose normalization. Header inspection before decoding uses Pillow to enforce decoded-size bounds. Limits are initial engineering choices, not assignment criteria.
