# Lab 5 Implementation Plan

**Goal:** LFW PCA/eigenfaces and held-out RBF SVM recognition in shared lab UI.

**Architecture:** Explicit setup caches LFW data under ignored backend/.cache/lfw. Stateless runs refit training-only PCA/SVM on a fixed 80/20 split in the existing threadpool, guarded against concurrent Lab 5 fits. No fitted-model persistence or queue. A separate full training-only spectrum determines the 90% threshold without guessing beyond the selected components.

**Stack:** Existing React/TypeScript, FastAPI, scikit-learn and NumPy.
