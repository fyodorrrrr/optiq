# Homepage Implementation Plan

> Execute inline using the executing-plans skill.

**Goal:** Ship the approved homepage with a full-screen introduction and freely selectable seven-lab map.

**Architecture:** React owns the introduction and selected-lab state. A typed lab catalogue supplies labels, descriptions, icons, and availability. A dedicated map component renders nodes and selected details. The existing browser prototype remains explicitly a preview, not a Python implementation.

**Stack:** Existing React, TypeScript, Vite, Tailwind; no runtime dependencies added.

**Spec:** `docs/DESIGN_FOUNDATION.md`, `docs/PRD.md`, and approved homepage browser mockup. User refinement: introduction fills the first screen.

## Constraints and Review Focus

- Preserve neutral tokens and shallow dimensional nodes; no locks or false completion.
- Keep seven labs in logical keyboard order, including the reverse-direction second row.
- Avoid horizontal overflow on small screens; respect reduced motion.
- Preview navigation must work without the temporary companion server.
- Preserve the backend health check as a secondary development utility.
