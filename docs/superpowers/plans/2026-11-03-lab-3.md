# Lab 3 Implementation Plan

**Goal:** Implement histogram equalization, CLAHE, and linear contrast adjustment/stretching using the shared laboratory UI.

**References:** Lab 3 in `docs/LAB_REQUIREMENTS.md`, `docs/PRD.md`, and `docs/ARCHITECTURE.md`.

**Approach:** one stateless request runs every method on the same working original. Grayscale mode uses one intensity channel; color mode changes Y in OpenCV YUV and reconstructs BGR. Histograms and statistics are calculated from each actual displayed output, including reconstruction rounding/clipping. Original/global/CLAHE appear together; the linear result is also visible. Charts share the same count scale for fair comparison.

**Linear conventions:** manual adjustment is `clip(rint(alpha * channel + beta), 0, 255)`; automatic stretching maps the observed minimum/maximum to 0/255, leaving constant inputs unchanged. Defaults: grayscale, CLAHE clip limit 2, tiles 8×8, manual scale 1.2 and offset 0. Inputs retain existing PNG/JPEG bounds. Samples are generated, with deterministic noise.
