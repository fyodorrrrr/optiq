custom inference is enabled only when valid custom weights exist. No checkpoint
uploads or user-provided executable code. No fabricated training charts/results.
Model/data downloads happen through explicit setup, not a prediction request.

## Alternatives and tradeoffs

- Local CLI training plus artifact review (recommended): fits the current app
  and lab scope; long runs happen outside request handlers. Requires a dataset
  and an explicit preparation/training step on each development environment.
- Browser-started background training: needs job lifecycle, persisted status,
  cancellation, resource isolation, and deployment decisions. This adds training
  infrastructure excluded from the initial scope and requires separate approval.
