Before you try

Will the image dimensions change when its colors are removed?

Each experiment starts from the original image.

Same dimensions. Different information.

A color image stores red, green, and blue values at each pixel. A grayscale image represents each pixel with one intensity value. Width and height stay the same.

How this connects to Python

The working lab will use OpenCV’s BGR-to-grayscale conversion. This preview uses a browser approximation; it is not the final algorithm implementation.

Make sense of the result

Find two areas that had different colors. Are they still easy to distinguish in grayscale? Color and brightness carry different kinds of information.
